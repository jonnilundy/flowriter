# A quiet first draft

The page is a column of plain text. Markdown stays **literal**: the marks are there, in a softer colour, and nothing moves when you type them.

## What a morning needs

- one file, open
- a list that continues on Return
  - and nests with Tab
- [ ] a task for later

> Write first. Arrange after.

Code keeps its `backticks`, and a link is just [text](https://example.com).
