Flowriter 0.5.0 can print.

- File > Print (Command-P) prints the note as you typed it, in black. Headings and bold text print in the bold face, italic text in the italic face
- The print panel's Flowriter section picks the font and its size, and can start a new page at each `---`. The rule itself does not print, and front matter and code blocks never break a page. Flowriter keeps the choices for the next print
- File > Page Setup (Shift-Command-P) sets the paper size and orientation
- Bold text is lantern yellow and italic text is rose, so both stand out from the running text
