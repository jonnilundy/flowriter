Flowriter 0.2.0 is a new app. It replaces the earlier editor with a plain one: your Markdown stays literal, and nothing moves while you type.

- Markdown shows as colour and weight on the text you typed. Every line has the same height
- One note per window, in a centred column
- Notes drawer beside the page (Option-O), for cut text and side thoughts. Shift-Command-M moves the selection there
- Command-N opens a note with no file. Its first line names it, and a click on the name in the top bar saves it
- One sheet saves, renames, moves and asks before closing an unsaved note
- Saved locations: File > Locations sets where new notes go
- Unsaved notes are kept as drafts and come back at the next launch
- Focus Mode (Shift-Command-F) keeps the caret line in the middle of the window
- Lists continue on Return and nest with Tab

Not in this version: ghosts, alternatives, the overflow panel, rendered tables, math, Mermaid and images, and languages other than English. Files written with 0.1 open as plain Markdown. Their `.flowriter.json` sidecar files are not read.
