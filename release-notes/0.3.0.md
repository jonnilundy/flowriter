Flowriter 0.3.0 has a new typeface and a new key for moving lines.

- The page, the notes and the app's controls use Paper Mono, a free monospaced font by Paper. Italic is the upright face slanted, so every line still keeps the same character grid
- Control-Command-Up and Control-Command-Down move the current line, or the selected lines, up or down. It works on the page and in the notes, and Undo takes each move back
